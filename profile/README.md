## Troubleshooting Common Issues

Install issues? Update the Office apps to the supported channel before reporting that Copilot is missing.  
Performance problems? Check tenant policy and licence assignment if the pane appears but features are greyed out.  
License/activation? Verify file permissions when answers ignore a document the user expects to be in scope.  
Compatibility? Sign out and back in to refresh the authentication token after a password change.  
Update failures? Confirm the region and data policy with IT before assuming a feature is broken.
